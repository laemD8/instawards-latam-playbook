# Instawards LATAM Playbook

Internal operating playbook for the Instawards LATAM program run by BAF across Argentina, Bolivia, Peru, Colombia, Mexico and Costa Rica.

The page covers the monthly selection cycle, active-project monitoring, owners by person and country, the next four rounds with exact dates, a per-person calendar and a live workload model.

## Use

`index.html` is a single self-contained file. Open it in a browser, or publish it with GitHub Pages (Settings > Pages > Deploy from branch > `main` / root).

It needs an internet connection only to load the Lora and Inter fonts from Google Fonts.

## Notes

- Dates are calculated from the visitor's current date.
- Holidays are not included in business-day calculations.
- Workload figures are planning estimates from the methodology, not guaranteed consumption.
